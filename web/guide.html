本服务只负责代理连通性，不判断业务站点风控，不接收下游业务反馈。

警告：公共代理不可信，仅限合法授权用途。请先阅读完整免责声明。

API 领取

curl --noproxy '*' 'http://<部署机地址>:21992/api/v1/proxies/random'

reach 支持 any、domestic、overseas、both。

返回的是具体代理 URI。普通 HTTP/SOCKS5 使用原地址，Mihomo 节点使用部署机上对应的独立端口，不提供统一轮换入口。

导出

  • /connectivity/proxies.txt
  • /connectivity/proxies.uri
  • /connectivity/proxies.base64
  • /connectivity/proxies.csv
  • /connectivity/records.json
  • /connectivity/clash.yaml

检测

国内、国外检测目标与可选的出口识别目标全部由部署者自行配置。发布包不内置任何第三方地址。

业务站点的账号风控、限流和 Cookie 状态由使用端自行管理。
