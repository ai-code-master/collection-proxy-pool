# 使用方法

## API 领取

```sh
curl --noproxy '*' "http://${POOL_HOST}:21992/api/v1/proxies/random"
```

需要指定连通范围时：

```sh
curl --noproxy '*' "http://${POOL_HOST}:21992/api/v1/proxies/random?reach=domestic"
curl --noproxy '*' "http://${POOL_HOST}:21992/api/v1/proxies/random?reach=overseas"
curl --noproxy '*' "http://${POOL_HOST}:21992/api/v1/proxies/random?reach=both"
```

返回值同时包含完整 `proxy` URI 和独立的 `scheme`、`host`、`port`字段。
普通 HTTP/SOCKS5 代理保留原地址；Mihomo 节点返回部署机的对应独立端口。端口从 `mihomo.json` 的 `base_port` 开始，数量跟随当前节点数量。不提供统一轮换入口。
旧的 `/next` 接口作为兼容入口继续可用。

## 批量获取

标准 JSON 列表使用 `/api/v1/proxies`，支持 `limit`、`offset`、`protocol` 和 `reach` 筛选：

```sh
curl --noproxy '*' "http://${POOL_HOST}:21992/api/v1/proxies?limit=100"
```

- `/connectivity/proxies.txt`
- `/connectivity/proxies.uri`（每行一个完整代理 URI）
- `/connectivity/proxies.base64`（对 URI 清单整体进行 Base64 编码）
- `/connectivity/proxies.csv`
- `/connectivity/records.json`
- `/connectivity/provider.yaml`
- `/connectivity/clash.yaml`

返回中的 `domestic` 和 `overseas` 表示最近一次尚未过期的用户自定义区域检测结果。只有配置了用户选定的出口识别目标时，才会生成 `exit_ip`、`country`、`geo_checked` 和 `exit_info`。

## 下游责任

下游自行决定代理租用时长、请求频率、并发、Cookie 和业务结果处理。代理池不保证任何特定站点的可用性。
