# 局域网部署边界

本项目按单用户、可信局域网或 Tailscale 自用设计，不提供登录鉴权。

## 网络边界

- 不要把 21992 或 Mihomo 的 `25001+` 端口映射到公网。
- 路由器、云安全组和主机防火墙应只允许可信内网访问。
- `/healthz` 不需要认证，只返回状态和软件版本，不包含代理数据。
- 如果未来需要跨公网访问，应先通过 Tailscale/WireGuard 建立私网。

## 数据边界

运行数据库、日志、代理清单和出口 IP 都位于 `PROXY_POOL_DATA`。`config.json`、`sources.json` 和 `mihomo.json` 也是本地私有配置。这些内容不属于发布包，也不应提交到公共代码仓库或构建进容器镜像。

## 限速

服务默认按直连客户端地址限制为每分钟 120 次。反向代理部署时，应用看到的可能是网关地址，应同时在网关层配置按真实客户端 IP 的限速。
